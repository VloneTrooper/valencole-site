Aviva Manual

A searchable, mobile-first employee manual for a medical spa, replacing a set of scattered PDFs, group chat messages and a printed binder.

The problem

The spa's policies existed, but they weren't anywhere useful. Some were in PDFs on a shared drive, some had only ever been said out loud in a group chat, and the printed binder was accurate as of a while ago. The practical result was that staff asked a manager instead of looking anything up, and the manager answered the same handful of questions every week.

What I built

One web app holding the whole manual, indexed for fuzzy search, organized into chapters with role-based navigation so an esthetician and a front-desk hire don't wade through each other's material. Password protected, on the spa's own domain, styled to match their branding so it reads as theirs rather than as a generic tool.

The constraint that shaped it

The person using this is not sitting at a desk. They're between clients, on their feet, with about ten seconds and a phone in one hand. That ruled out anything requiring navigation by browsing — you have to be able to type three words and land on the paragraph you need. Search came first and the layout was built around it, rather than the other way around.

It's in daily use. The measure that mattered to me was whether the manager kept getting asked the same questions, and she doesn't.
